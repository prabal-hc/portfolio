# Prabal Holla — Portfolio

A scroll-driven 3D portfolio built around a Royal Enfield Hunter 350. As you scroll, the camera glides around the bike — overhead on the console, side-on to the engine, close on the front brakes, behind the tail light — while each section's content slides in beside it.

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Three.js / React Three Fiber · Lenis (smooth scroll)

## Run it

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## How it's put together

| Path | What it does |
| --- | --- |
| `src/data/content.ts` | All the words: hero, about, skills, projects, journey, contact. Edit this to change the content. |
| `src/lib/cameraPath.ts` | The camera keyframes, one per section, and the spline that glides between them. |
| `src/lib/layout.ts` | The single rule for *side-by-side* vs *stacked* layouts, shared by the CSS and the camera. |
| `src/lib/scroll.ts` | Maps scroll position to camera progress. |
| `src/components/three/SketchfabStage.tsx` | Drives the bike viewer's camera from scroll. |
| `src/components/Sections.tsx` | The page content and its responsive layout. |
| `tools/blender/build_hunter350.py` | A Blender script that builds a stylised Hunter 350 and exports it to `public/models/hunter350.glb` (alternative to the embedded model). |

The layout is fully responsive: text sits beside the bike on laptops, desktops and landscape tablets, and underneath it on phones and portrait tablets. The camera re-frames itself for every screen shape.
